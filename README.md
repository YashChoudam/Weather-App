# Weather-App
A simple weather app that shows real-time weather info for any city. Enter the city name to get temperature, humidity, wind speed, and conditions using live data from a weather API. Clean UI, responsive design, and fast performance for quick forecasts.

## Installation
1. Clone the repo: `git clone https://github.com/YashChoudam/Weather-App.git`
2. Install dependencies: `npm install`
3. Set environment variable: `API_KEY=your_openweathermap_api_key` in a `.env` file
4. Start the server: `npm start`

## Deployment
Deployed on Render: [https://weather-app-d4uw.onrender.com](https://weather-app-d4uw.onrender.com)

## Usage
Enter a city name (e.g., Mumbai) and click "Get Weather" to see the current weather.
